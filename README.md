# Comp249-TUT

面向 Java 初学者的 COMP249 Tutor 配置，无需 API key 或额外依赖。

在支持 `AGENTS.md` 的 coding assistant 中打开这个项目，助手会遵循 [Tutor 规则](AGENTS.md)。这个文件是助手指令，不是独立运行的 Java 程序。

使用时提供：

1. 作业要求，包括限制和输出格式。
2. 需要检查的 `.java` 文件。
3. 编译报错、实际输出及预期输出（如果有）。

默认只给修改建议，按“文件名和行号 → 原代码 → 修改后的代码 → 一句中文解释”反馈。

- 输入“只给修改”：省略解释。
- 输入“直接帮我改文件”：授权助手修改相关 Java 文件，并在条件允许时编译或运行验证。
